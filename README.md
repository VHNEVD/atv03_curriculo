## 🎯 Objetivo do Projeto

O objetivo deste projeto é construir a estrutura de um portfólio/currículo web reproduzindo fielmente o layout e os tópicos propostos, aplicando as melhores práticas de marcação semântica em HTML5, sem a necessidade do uso de estilização CSS avançada.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântica pura, tabelas, formulários e links de navegação)

---

## 📌 Funcionalidades e Estrutura

- **Cabeçalho (`<header>`):** Nome/cargo do desenvolvedor e menu de navegação interna com links âncora (`#sobre`, `#projetos`, `#contato`).
- **Seção "Sobre Mim" (`<section>`):**
  - Foto de perfil com dimensões ajustadas (150x150px).
  - Texto de apresentação com destaques de formatação.
  - Lista não ordenada com as principais habilidades.
- **Seção "Meus Projetos" (`<section>`):**
  - Tabela organizada com tags semânticas (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`) listando os projetos, tecnologias, status e links.
- **Seção "Entre em Contato" (`<section>`):**
  - Formulário completo envolvido por `<fieldset>` e `<legend>`.
  - Campos de entrada para *Nome*, *Email*, menu suspenso (`<select>`) para *Assunto*, área de texto (`<textarea>`) para *Mensagem* e botão de envio.
  - Todos os campos devidamente vinculados aos seus `<label>`.
- **Rodapé (`<footer>`):**
  - Informações de direitos autorais com caractere especial (`&copy;`), e links diretos para e-mail (`mailto:`) e telefone (`tel:`).
